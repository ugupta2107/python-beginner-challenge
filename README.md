# Python Beginner Challenge & Student Management System

This repository contains my solutions for the Python Beginner Challenge (Part 1) and a command-line Student Management System mini-project (Part 2).

## Folder Structure
- `part1_fundamentals/` — Exercises covering variables, data types, operators, conditionals, loops, lists, dictionaries, functions, file handling, and error handling.
- `part2_mini_project/` — Menu-driven Student Management System (`student_management.py`) with text file persistence (`students.txt`).
- `screenshots/` — Output screenshots showing the Student Management System in action.

## How to Run
1. Make sure Python 3 is installed on your system[cite: 3].
2. Open a terminal or Spyder IDE in the project folder.
3. Run the mini-project using:
   ```bash
   python part2_mini_project/student_management.py
